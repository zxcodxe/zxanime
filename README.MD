ZX Anime File Store Bot

A simple Telegram Anime File Store Bot.

🚀 Deploy on Heroku

""Deploy" (https://www.herokucdn.com/deploy/button.svg)" (https://heroku.com/deploy?template=https://github.com/zxcodxe/zxanime)

📦 Repository

GitHub: "zxcodxe/zxanime" (https://github.com/zxcodxe/zxanime)

⚙️ Configuration

Before running the bot, configure the required Telegram and database values according to the project's configuration files.

Required values include:

- "BOT_TOKEN"
- "API_ID"
- "API_HASH"
- "DB_URI"
- "DB_NAME"
- "ADMINS"
- "FSUBS"

🛠️ Run

The project uses the following Heroku process:

web: python3 main.py

⚠️ Important

Do not publish your Telegram bot token, API credentials, or database credentials publicly.
